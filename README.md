# Data Type Player Status Tracker

Create a Python program in `main.py` that stores and updates information about a video game player. This activity focuses on the skills from the slideshow: creating variables, using appropriate datatypes, displaying values with `print()`, changing variable values, and using descriptive variable names.

## Requirements

* [ ] Create a variable for the player's name with a **string** value.
* [ ] Create a variable for the player's level with an **integer** value.
* [ ] Create a variable for the player's health with a **float** value.
* [ ] Create a variable for the player's number of lives with an **integer** value.
* [ ] Create a variable that stores whether the player has a key using a **Boolean** value.
* [ ] Use clear and descriptive `snake_case` variable names.
* [ ] Use `print()` to display the player's starting information using the variables you created.
* [ ] Reassign each value *after* it has been printed already to the console.
* [ ] Use `print()` to show the reassigned values by displaying the new player information.

## Assessment — 20 Marks

| Assessment Item | Criteria | Marks |
|---|---|---:|
| Player Variables | Creates variables for player name, level, health, number of lives, and key status. | 4 |
| Appropriate Datatypes | Uses a `str` for the name, `int` values for level and lives, a `float` for health, and a `bool` for key status. | 4 |
| Variable Naming | Uses clear and descriptive `snake_case` variable names. | 2 |
| Starting Output | Uses `print()` to display the original values stored in the player variables before they are changed. | 3 |
| Reassigning Variables | Reassigns each existing variable to a new value after the original values have been displayed. | 4 |
| Updated Output | Uses `print()` to display the new values stored in the reassigned variables. | 3 |
|  | **Total** | **20** |
